# MAISON website

A responsive HTML/CSS/JavaScript recreation of the MAISON Figma landing page.

## Run it
1. Extract the ZIP.
2. Open the `maison-website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — page structure
- `style.css` — layout and styling
- `script.js` — mobile navigation interaction
- `images/hero.jpg` — exported Figma hero image

The collection section currently reuses the supplied hero image as a temporary product image. Replace it with your product image when you export that asset from Figma.
